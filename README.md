# Strategic Financial Dashboard

A zero-backend, single-file financial cockpit for a fictional conglomerate (**NexaGroup**): budget vs
actual per business unit, cost structure, sales, marketing ROMI, workforce and production/inventory — all
driven by sidebar SBU and period filters, all charts Chart.js, all data inline and synthetic.

**Open `index.html` in a browser. Nothing to install, nothing to build.**

→ Full write-up — problem, solution, feature list, tech stack, architecture history, synthetic-data
  disclaimer, run and deploy notes — is in **[PROFILE.md](PROFILE.md)**.

## Disclaimer

All companies, units, campaigns and figures are fictional and synthetically generated (BDT crore,
monthly, Jan 2025 – Jun 2026). No real organisation or financial record is represented.
